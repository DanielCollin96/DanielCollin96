# Hi, I'm Daniel 👋

PhD candidate in Computer Science (TU Berlin & GFZ Helmholtz Centre for Geosciences, Potsdam).
I build probabilistic machine learning models for forecasting extreme events, applied to space weather:
predicting the solar wind and coronal mass ejections (CMEs) from solar images and coronagraph observations.

**Research interests:** uncertainty quantification · distributional regression · imbalanced regression · deep learning · forecasting with scientific data

## Featured projects

| Project | What it does | Links |
|---|---|---|
| **PROSWIN** | Probabilistic 4-day solar wind speed forecasts from multi-channel solar images using a Swin Transformer and deep distributional regression. | [Code](https://github.com/DanielCollin96/proswin) · [Paper](https://doi.org/10.48550/arXiv.2609.26683) · [Dataset](https://doi.org/10.5880/gfz.ojsj.2026.001) |
| **Solar wind from coronal holes** | Parameter-efficient solar wind speed model (~100 parameters) using features from coronal-hole segmentation maps. | [Code](https://github.com/DanielCollin96/hss_prediction) · [Paper](https://doi.org/10.1029/2024SW004125) · [Dataset](https://doi.org/10.5880/GFZ.2.7.2024.001) |
| **Solar image processing** | Library with downloading and preprocessing routines for solar images (science and real-time data) | [Code](https://github.com/DanielCollin96/solar_image_processing) |
